# 2026.246.0100 — feat: OpenClaw 2.0 (npm openclaw@2026.8.2)

## Summary

Bump the openclaw npm package from `2026.7.1-2` (pre-2.0) to `2026.8.2` — the latest
stable patch of **OpenClaw 2.0** (v2026.8.1, the "2.0" release). The gateway startup
surface is unchanged in 2.0: the supervised exec line
(`openclaw gateway --port 18789 --allow-unconfigured --bind loopback`), the
`gateway.mode=local` config guard, and the `~/.openclaw/openclaw.json` JSON5 config
all carry over verbatim, so the candy's service/port/volume wiring is untouched.

What changes:

- **package.json** — `openclaw` dependency `2026.7.1-2` → `2026.8.2`.
- **plan** — the version check now matches `2026.8.2`; a new runtime check asserts the
  gateway's **`/healthz` liveness endpoint** (a 2.0 container-probe addition) returns
  200, replacing bare TCP reachability as the gateway-health assertion.
- **description / skill** — prose updated for 2.0 (version, `/healthz` probe).

2.0 breaking changes that do NOT affect this candy: the `codex/*` → `openai/*` model
route unification (operator config, not image content), OpenProse retirement, and the
`openclaw doctor --fix` migrations (QMD memory, execSecurity/execAsk, HEARTBEAT.md) —
all apply to an operator's `~/.openclaw` data volume, which is fresh in beds and
documented in the openclaw-deploy skill update.
